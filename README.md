# Calculadora em C++

Uma calculadora simples feita em C++.

Este foi um dos meus primeiros projetos enquanto aprendia programação e a linguagem C++.

## O que o programa faz

* Soma
* Subtração
* Multiplicação
* Divisão

## Conceitos praticados

* Variáveis
* Entrada e saída com `cin` e `cout`
* Operadores matemáticos
* Estruturas condicionais (`if` e `else`)
* Organização básica de um programa em C++
